# Проверка подключения к серверу

## Быстрая проверка

1. **Сервер отвечает на ПК?** `http://localhost:8080/api/users` — должен вернуть JSON ✓

2. **Эмулятор или телефон?**
   - **Эмулятор** → `USE_EMULATOR = true` (адрес 10.0.2.2)
   - **Телефон** → `USE_EMULATOR = false` (адрес 10.1.30.146 — ваш Wi‑Fi)

3. **Главное: брандмауэр Windows** блокирует входящие соединения!
   Запустите **от имени администратора**: `add_firewall_rule.bat`

## Добавить правило брандмауэра (обязательно!)

1. Правый клик по `add_firewall_rule.bat` → «Запуск от имени администратора»
2. Или вручную в cmd (от админа):  
   `netsh advfirewall firewall add rule name="Spring Boot 8080" dir=in action=allow protocol=TCP localport=8080`

После этого эмулятор и телефон смогут подключиться.
