# Техническое задание на разработку программного продукта для планирования встреч

## 1. Общие описание
Необходимо разработать программный продукт для планирования встреч сотрудников внутри компании. Система состоит из клиентского мобильного приложения и серверной части.

## 2. Клиентская часть (Android-приложение)
Клиентом является **Android-приложение**, которое должно быть реализовано на **Kotlin** или **Java** с использованием **адаптивной верстки**.

Приложение должно предоставлять интуитивно понятный интерфейс, в котором реализован следующий функционал:

*   **Регистрация и авторизация** сотрудника.
*   **Настройка личного профиля**.
*   **Создание встречи** с возможностью приглашения других сотрудников. Приглашенные сотрудники должны иметь возможность дать бинарный ответ (**принял** / **не принял**).
*   **Просмотр списка активных приглашений** на встречи с возможностью дать ответ о возможности посещения.
*   **Просмотр собственного расписания встреч** в разрезе дня, недели и месяца.

**Важное условие:** временные слоты для встреч разбиты строго по часам. Например, можно создать встречу на 9:00–10:00, но создание встречи на 9:10, 9:05 и т.д. — невозможно.

## 3. Серверная часть
Сервер представляет собой **микросервис на Spring Boot**, работающий с СУБД **PostgreSQL** или **H2**.

Серверное приложение должно:
*   Предоставлять API, необходимый для полноценной работы мобильного приложения.
*   Осуществлять все основные операции с данными в базе через **Spring Data JPA**.
*   Использовать **Liquibase** для создания схемы базы данных и ее предзаполнения.



# User stories:

* Как пользователь, я хочу иметь возможность зарегистрироваться в приложении, чтобы получить доступ к его функциям.

* Как зарегистрированный пользователь, я хочу иметь возможность сохранять сеанс, чтобы не тратить время для повторных авторизаций.

* Как пользователь, я хочу иметь возможность настраивать свой личный профиль, чтобы остальные сотрудники могли меня отличать.

* Как пользователь, я хочу иметь возможность просматривать список всех сотрудников компании, чтобы созданвать с ними встречи.

* Как пользователь, я хочу иметь возможность создавать встречи и отправлять приглашения моим коллегам, чтобы обсуждать важные для компании темы.

* Как пользователь, я хочу видеть список активных приглашений на встречи и иметь возможность дать на них ответ (принял/не принял), чтобы планировать своё расписание.

* Как пользователь, я хочу иметь возможность просматривать собственное расписание встреч в специальном для этого разделе, чтобы знать, когда и во сколько у меня назначена встреча.

# User cases:

## Регистрация:

* Цель: регистрация пользователя

* Участники: незарегистрированный пользователь

* Предусловия: учетная запись не создана

* Основной поток: Ввод email, пароля, потверждения пароля, идентификатора организации, имени и фамилииы. Отправка запроса регистрации на сервер. Получение проверочного кода для подтверждения email. Ввод проверочного кода. Отправка запроса потверждения регистрации на сервер. Передача токена авторизации на устройство. Сохранение токена авторизации на устройстве. Вход в систему с токеном.

* Альтернативный поток: Ошибка. Некорректный формат email, неверный email -> Сброс поля ввода текста с индикацией и обозначением ошибки. Неверный проверочный код -> сброс поля ввода кода с индикацией ошибки, активация кнопки для повторной отправки кода.

## Авторизация:

* Цель: авторизация пользователя

* Участники: пользователь

* Предусловия: учетная запись создана

* Основной поток: Проверка хранилища на существующий токен авториции, при присутствии - вход в систему по токену, если токен отсутствует - ввод email и пароля. Отправка запроса авторизации на сервер. Сравнение отправленных данных с данными из БД. Передача токена авторизации на устройство. Сохранение токена авторизации на устройстве. Вход в систему с токеном.

* Альтернативный поток: Ошибка. Некорректный формат email, неверный email -> Сброс поля ввода текста с индикацией и обозначением ошибки. Неверный пароль код -> сброс поля ввода пароля с индикацией ошибки.

## Редактирование личного профиля:

* Цель: Редактирование личного профиля пользователя

* Участники: пользователь

* Предусловия: учетная запись создана

* Основной поток: Выбор значения поля для изменения. Ввод нового значения поля. Отправка на сервер нового значения поля. Изменение в базе данных старого значения поля на новое. Отправка запроса на повторный запрос клиента к серверу для отображения применившегося изменения. 

* Альтернативный поток: Ошибка. Введенное значение не может быть применено к данному полю -> возвращения значения поля на предыдущее.

## Просмотр списка:

* Цель: просмотр списка сотрудников компании

* Участники: пользователь

* Предусловия: учетная запись создана

* Основной поток: Проверка компании, которой принадлежит пользователь. Запрос на сервер со списком сотрудников компании. Отправка списка сотрудников компании. Занесение полученого списка в соответствующий интерфейс.

* Альтернативный поток: Ошибка. Отсутстивие пользователя в компании -> вывод пустого списка, гласящего о том, что сотрудник не состоит в какой-либо компании. Отсутстивие сотрудников в компании -> вывод пустого списка, гласящего о том, что в компании пользователя нет сотрудников на даннный момент.

## Создание встречи:

* Цель: Создание встречи 

* Участники: пользователь

* Предусловия: учетная запись создана, пользователь находится в какой-либо компании

* Основной поток: Отправка запроса на сервер со списком сотрудников. Принятие списка сотрудников. Выбор списка сотрудников для встречи. Переход на экран с полем для названия встречи, времени встречи и места встречи. Отправка списка выбранных сотрудников, названия встречи, времени встречи и места встречи. Занесение полученных данных в новый экземпляр встречи. Отправка приглашения на встречу указанным пользователям. Отправка всем участникам встречи созданного на сервере экземпляра для последующего использования информации. 

* Альтернативный поток: Ошибка. Отсутстивие отправленного названия встречи -> Выставление названия встречи по принципу: типовое название + номер встречи. Отсутстивие отправленного времени встречи -> невозможность создания встречи до момента, пока пользователь не выберет время. Отказ от встречи одним из отрудников -> Удаление сотрудника из встречи.

## Отправка приглашения на встречу:

* Цель: Отправить приглашение сотруднику для участия во встрече

* Участники: пользователь, сотрудник

* Предусловия: учетная запись создана, пользователь и сотрудних находятся в одной и той же компании

* Основной поток: Выбор встречи. Выбор пункта с отправкой приглашения на встречу. Выбор сотрудников для приглашения на встречу. Отправка запроса на сервер на отправку выбранным пользователям уведомления о том, что их приглашают на встречу. Принятие получателями встречи. Добавление принявших приглашение во встречу. Отправка всем участникам встречи созданного на сервере экземпляра для последующего использования информации.

* Альтернативный поток: Ошибка. Отказ от встречи сотрудником -> Удаление сотрудника из встречи.


## Просмотр расписания:

* Цель: просмотр расписания встреч

* Участники: пользователь

* Предусловия: учетная запись создана, пользователь находится в какой-либо компании

* Основной поток: Запрос на сервер с просмотром расписания встреч. Получение даты и времени всех встреч пользователя. Занесение дат и времен встреч в список. Отправка списка пользователю. Парсинг списка. Занесение и выделение в календаре дней, которые есть в списке 

* Альтернативный поток: Ошибка. Отсутстивие встреч -> вывод обычного календаря без выделенных дней встреч.

# Задачи:

## Регистрация и авторизация:
### Реализовать экран регистрации:
* Ввод email.
* Ввод пароля.
* Ввод огранизции.
* Ввод фамилии, имени.
* Подтверждение email с помощью электронного письма.
* Обработка ошибок.
* Отправка регистрационных данных пользователя на сервер.
* Получение токена авторизации.
* Обработка ошибок.

### Реализовать экран авторизации:
* Ввод email.
* Ввод пароля.
* Реализация сброса пароля.
* Отправка авторизационных данных пользователя на сервер.
* Получение токена авторизации.
* Обработка ошибок.

## Личный профиль и настройки
### Реализовать экран редактирования профиля:
* Получение личного профиля и его данных.
* Отправка обновлённых данных личного профиля на сервер.
* Обработка ошибок.

## Управление встречами
### Реализовть экран создания встречи:
* Ввод названия встречи.
* Выбор целочасовых временных слотов для встреч.
* Выбор участников встреч из списка сотрудников.
* Отправка данных встречи на сервер.
* Обработка ошибок.

## Управление приглашениями
### Реализовать экран приглашений на встречи:
* Уведомления о поступающих встречах.
* Показ только нерассмотренных встреч.
* Выбор для каждой встречи - принимать или не принимать участие в ней.
* Отправка данных о принятии / непринятии на сервер.

## Расписание встреч
### Реализовать экран расписания встреч в разрезе дня, недели и месяца:
* Отправка запроса серверу для каждого вида разреза при изменении такового.
* Показ только тех встреч, в которых сотрудник принимает участие.
* Обработка ошибок.
